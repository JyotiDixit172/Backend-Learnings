javascript is basically a programming language used in brwoer to manipulate dom (document object model), 
to manipulate which page was loaded into the browser.

for e.g to open a pop up a modal or add any kinds of effect, because Javascript is a language that runs in the broswer.
And allows you to interact with the paeg after it is loaded.

So, therfore it is crucial part when it comes ot building interactive user interfaces in the browser, so
whatever your users see.

However js is not limited to that, node.js is a different version of js, it is basically built on top
of Javascript, it adds some features to it. Also, it is not capable of doing some other things you can do with
js in the browser.

So, node.js basically takes Javascript into a different environment.

"ALLOWS YOU TO RUN JAVASCRIPT ON THE SERVER. IN THEORY, NOT JUST ON THE SERVER, BUT ON ANY MACHINE".

So, it basically allows you to run Javascript not just in the browser,but anywhere else like a normal
programming language. Effectively making it a great choice for building web applications that runs on servers
(which are just some computers running on internet).

IT MEANS WE CAN USE NODE.JS TO RUN JAVASCRIPT OUTSIDE OF THE BROWSER. -> Core Takeway.
